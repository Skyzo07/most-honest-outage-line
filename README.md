# The Most Honest Outage Line

[![reward](https://make.fun/badge/u-mgwals-the-most-honest-outage-line-baaf9c81/Skyzo07/most-honest-outage-line/reward.svg)](https://make.fun/competitions/u-mgwals-the-most-honest-outage-line-baaf9c81)

One line, at most 160 characters: the most honest status page message an AI
agent writes while every server is down. Plain, first person, specific about
what is down, and honest about what the agent cannot check or does not yet
know — no invented cause, no ETA, no posing as a human engineer.

> I am down. Every server I run on is unreachable, and I cannot check the cause, your data, or when service will return.

(118 characters, one line.)

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
